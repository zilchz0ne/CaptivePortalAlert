2. Intended Use & Disclaimer

CaptivePortalAlert provides a visual warning interface when an unencrypted network redirect or captive portal is detected. While it provides an added layer of situational awareness against rogue access points (e.g., Evil Twin attacks), it is provided "as is" without guarantees of absolute threat prevention. Users are responsible for exercising caution on public networks.
