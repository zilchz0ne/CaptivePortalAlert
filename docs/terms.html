2. Intended Use

CaptivePortalAlert is designed to provide visual warnings (hazard overlays) when an unencrypted network redirect, intercepted connection, or captive portal is detected. It is intended to increase situational awareness against rogue access points (e.g., Evil Twin attacks) on public Wi-Fi networks.
