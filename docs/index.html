🛡️ CaptivePortalAlert

A lightweight Chrome extension engineered to flag untrusted Wi-Fi captive portals and defend against Evil Twin and phishing attacks on public networks.

⚠️ SECURITY ALERT: UNTRUSTED CAPTIVE PORTAL ENVIRONMENT

How It Works

  • Probe Detection: Monitors initial HTTP network probes to catch active network interception.
  • Visual Isolation: Enforces a prominent high-visibility defensive border around untrusted captive portal login pages.
  • Tab Inheritance: Tracks child tabs spawned by captive portal landing pages to ensure rogue login frames remain isolated.
