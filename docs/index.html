CaptivePortalAlert

Maintain situational awareness on untrusted public Wi-Fi networks.

Overview

CaptivePortalAlert is a defensive Manifest V3 browser extension built to protect users from entering sensitive credentials or personal data into untrusted portal screens, Evil Twin APs, or intercepted connections on public Wi-Fi networks.

Key Features

  • Automated Probe Detection: Intercepts standard connectivity check probes before pages finish loading.
  • Visual Hazard Overlay: Dynamically injects a high-visibility hazard border and warning banner over flagged portal pages.
  • Inherited Tab Protection: Automatically carries over danger flags to child tabs spawned from active captive portals.
  • Privacy-First: Runs entirely locally in your browser. Zero analytics, zero data collection, zero third-party logging.

How It Works

When you connect to an unauthenticated network, the extension monitors HTTP response codes from background probe checks. If network interception or a redirect is detected, a defensive UI frame is injected into the active browser tab to visually isolate the untrusted login page.
